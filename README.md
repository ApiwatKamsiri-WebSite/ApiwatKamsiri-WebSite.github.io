# ApiwatKamsiri-WebSite.github.io

เว็บส่วนตัวของ Apiwat Kamsiri — https://apiwatkamsiri-website.github.io

- `index.html` — หน้า intro + หน้าหลัก (โปรไฟล์, Task board, ลิงก์ & คลังส่วนตัว)
- `tasks.html` — timeline ของงาน
- `data/tasks.json` — งาน, วันหยุด, ลิงก์ทางลัด (แก้ได้จากหน้าเว็บในโหมดแก้ไข)
- `assets/data.js` — ข้อมูลโปรไฟล์

รันในเครื่อง: `python -m http.server 8080` แล้วเปิด http://localhost:8080
